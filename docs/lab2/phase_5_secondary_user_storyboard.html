Phase 5

Secondary User Storyboard & Adaptation

Adapting interaction for first-time / non-technical users to ensure error recovery

Target Secondary User

First-time user who has never used AI image generators and is unfamiliar with technical angle jargon.

Design Check Chosen

"Can the person correct it?"

Key Adaptation Strategy

Replace technical labels with visual icons + plain language, and add a prominent "Undo / Not happy" button.

Frame 2 Focus: Before vs. After Redesign

Before Redesign (Original Frame 2) Unclear / Stuck
Draft Image
Jargon Labels:
Angle: Orthographic 90°
Camera Azimuth: Top-Down
⚠️ No obvious Undo button!
Problem:

Technical angle labels; no undo — newcomer is stuck and unsure if a wrong tap can be reversed.

After Redesign (Newcomer-Friendly) Clear Correction Path
Draft Image
Visual Presets:
Eye-Level
Overhead
Side View

"Look at subject from directly above"

Solution:

Plain icons (eye-level / top-down / side view) + one-line explanation + clear "Undo / Not happy" button — understand at a glance, back out after a wrong tap.
