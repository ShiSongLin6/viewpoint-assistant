Simulation settings (for demonstrating the prototype)

The default reproduces the failure this project is about: models often return a similar orientation whatever angle the prompt states. When an angle is confirmed on the sphere, the simulated model always renders exactly that angle, standing in for a camera-controllable model. The simulated detector reads the angle of the placeholder render, so it is never wrong here; a real detector could be.
